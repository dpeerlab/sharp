# HTO DND - Demultiplex Hashtag Data (Docker)

Github: https://github.com/sail-mskcc/hto_dnd/

Example usage:

```
docker run --rm sailmskcc/hto-dnd:1.1.1 --help
```

## Manage

0. Update settings in `config.sh`
1. Build Docker Image `source build.sh`
2. Test Docker Image `source test.sh`
3. Push Docker Image `source push.sh`
